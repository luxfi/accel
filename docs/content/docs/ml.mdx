# ML Operations

The `MLOps` interface provides GPU-accelerated machine learning operations for neural network inference and training.

## Overview

```go
ml := session.ML()
```

Operations include:
- **Linear Algebra**: MatMul, transpose
- **Activations**: ReLU, GELU, Softmax
- **Normalization**: LayerNorm, BatchNorm
- **Attention**: Scaled dot-product attention
- **Convolutions**: Conv2D, MaxPool2D
- **Reductions**: Sum, Mean

## Matrix Operations

### MatMul

Performs matrix multiplication: C = A @ B

```go
// MatMul(a, b, c *UntypedTensor) error
// a: [M, K]
// b: [K, N]
// c: [M, N]

m, k, n := 1024, 1024, 1024

a, _ := accel.NewTensorWithData[float32](session, []int{m, k}, matrixA)
b, _ := accel.NewTensorWithData[float32](session, []int{k, n}, matrixB)
c, _ := accel.NewTensor[float32](session, []int{m, n})

if err := session.ML().MatMul(a.Untyped(), b.Untyped(), c.Untyped()); err != nil {
    log.Fatal(err)
}

result, _ := c.ToSlice()
```

### MatMulTranspose

Performs matrix multiplication with optional transposes.

```go
// MatMulTranspose(a, b, c *UntypedTensor, transposeA, transposeB bool) error
// C = A^T @ B or C = A @ B^T or C = A^T @ B^T

// C = A @ B^T
if err := session.ML().MatMulTranspose(
    a.Untyped(),
    b.Untyped(),
    c.Untyped(),
    false,  // don't transpose A
    true,   // transpose B
); err != nil {
    log.Fatal(err)
}
```

## Activation Functions

### ReLU

Applies rectified linear unit: y = max(0, x)

```go
// ReLU(input, output *UntypedTensor) error

input, _ := accel.NewTensorWithData[float32](session, []int{batch, features}, data)
output, _ := accel.NewTensor[float32](session, []int{batch, features})

if err := session.ML().ReLU(input.Untyped(), output.Untyped()); err != nil {
    log.Fatal(err)
}
```

### GELU

Applies Gaussian error linear unit activation.

```go
// GELU(input, output *UntypedTensor) error
// y = x * 0.5 * (1 + tanh(sqrt(2/pi) * (x + 0.044715 * x^3)))

if err := session.ML().GELU(input.Untyped(), output.Untyped()); err != nil {
    log.Fatal(err)
}
```

### Softmax

Applies softmax along an axis.

```go
// Softmax(input, output *UntypedTensor, axis int) error
// y[i] = exp(x[i]) / sum(exp(x))

// Softmax over last dimension
if err := session.ML().Softmax(input.Untyped(), output.Untyped(), -1); err != nil {
    log.Fatal(err)
}
```

## Normalization

### LayerNorm

Applies layer normalization.

```go
// LayerNorm(input, gamma, beta, output *UntypedTensor, eps float32) error
// y = gamma * (x - mean) / sqrt(var + eps) + beta

batchSize := 32
seqLen := 512
hiddenSize := 768

input, _ := accel.NewTensorWithData[float32](session, []int{batchSize, seqLen, hiddenSize}, data)
gamma, _ := accel.NewTensorWithData[float32](session, []int{hiddenSize}, gammaData)
beta, _ := accel.NewTensorWithData[float32](session, []int{hiddenSize}, betaData)
output, _ := accel.NewTensor[float32](session, []int{batchSize, seqLen, hiddenSize})

if err := session.ML().LayerNorm(
    input.Untyped(),
    gamma.Untyped(),
    beta.Untyped(),
    output.Untyped(),
    1e-5,
); err != nil {
    log.Fatal(err)
}
```

### BatchNorm

Applies batch normalization.

```go
// BatchNorm(input, gamma, beta, mean, variance, output *UntypedTensor, eps float32) error

if err := session.ML().BatchNorm(
    input.Untyped(),
    gamma.Untyped(),
    beta.Untyped(),
    runningMean.Untyped(),
    runningVar.Untyped(),
    output.Untyped(),
    1e-5,
); err != nil {
    log.Fatal(err)
}
```

## Attention

### Attention

Computes scaled dot-product attention.

```go
// Attention(q, k, v, output *UntypedTensor, scale float32) error
// output = softmax(Q @ K^T / scale) @ V

batchSize := 16
numHeads := 12
seqLen := 512
headDim := 64

// Q, K, V tensors: [batch, heads, seq_len, head_dim]
q, _ := accel.NewTensorWithData[float32](session,
    []int{batchSize, numHeads, seqLen, headDim}, queryData)
k, _ := accel.NewTensorWithData[float32](session,
    []int{batchSize, numHeads, seqLen, headDim}, keyData)
v, _ := accel.NewTensorWithData[float32](session,
    []int{batchSize, numHeads, seqLen, headDim}, valueData)
output, _ := accel.NewTensor[float32](session,
    []int{batchSize, numHeads, seqLen, headDim})

scale := float32(1.0 / math.Sqrt(float64(headDim)))

if err := session.ML().Attention(
    q.Untyped(),
    k.Untyped(),
    v.Untyped(),
    output.Untyped(),
    scale,
); err != nil {
    log.Fatal(err)
}
```

## Convolutions

### Conv2D

Performs 2D convolution.

```go
// Conv2D(input, kernel, output *UntypedTensor, stride, padding [2]int) error
// input: [batch, in_channels, height, width]
// kernel: [out_channels, in_channels, kernel_h, kernel_w]
// output: [batch, out_channels, out_height, out_width]

input, _ := accel.NewTensorWithData[float32](session,
    []int{32, 3, 224, 224}, imageData)
kernel, _ := accel.NewTensorWithData[float32](session,
    []int{64, 3, 7, 7}, weightData)
output, _ := accel.NewTensor[float32](session,
    []int{32, 64, 112, 112})

if err := session.ML().Conv2D(
    input.Untyped(),
    kernel.Untyped(),
    output.Untyped(),
    [2]int{2, 2},  // stride
    [2]int{3, 3},  // padding
); err != nil {
    log.Fatal(err)
}
```

### MaxPool2D

Performs 2D max pooling.

```go
// MaxPool2D(input, output *UntypedTensor, kernelSize, stride [2]int) error

if err := session.ML().MaxPool2D(
    input.Untyped(),
    output.Untyped(),
    [2]int{2, 2},  // kernel size
    [2]int{2, 2},  // stride
); err != nil {
    log.Fatal(err)
}
```

## Element-wise Operations

### Add

Performs element-wise addition.

```go
// Add(a, b, c *UntypedTensor) error
// c = a + b (with broadcasting)

if err := session.ML().Add(a.Untyped(), b.Untyped(), c.Untyped()); err != nil {
    log.Fatal(err)
}
```

### Multiply

Performs element-wise multiplication.

```go
// Multiply(a, b, c *UntypedTensor) error
// c = a * b (with broadcasting)

if err := session.ML().Multiply(a.Untyped(), b.Untyped(), c.Untyped()); err != nil {
    log.Fatal(err)
}
```

## Reductions

### Sum

Reduces tensor along specified axes.

```go
// Sum(input, output *UntypedTensor, axes []int) error

// Sum over batch dimension
input, _ := accel.NewTensorWithData[float32](session, []int{32, 100}, data)
output, _ := accel.NewTensor[float32](session, []int{100})

if err := session.ML().Sum(input.Untyped(), output.Untyped(), []int{0}); err != nil {
    log.Fatal(err)
}
```

### Mean

Reduces tensor along specified axes with mean.

```go
// Mean(input, output *UntypedTensor, axes []int) error

if err := session.ML().Mean(input.Untyped(), output.Untyped(), []int{0}); err != nil {
    log.Fatal(err)
}
```

## Dropout

### Dropout

Applies dropout with given probability (inference mode - no training support).

```go
// Dropout(input, output *UntypedTensor, p float32) error
// During inference, scales by (1-p)

if err := session.ML().Dropout(input.Untyped(), output.Untyped(), 0.1); err != nil {
    log.Fatal(err)
}
```

```text
│   │   ├── gemm.metal
│   │   └── gemm_splitk.metal
│   ├── attention/      # Attention kernels
│   │   ├── sdpa.metal  # Scaled dot-product attention
│   │   └── flash_attention.metal
│   ├── conv/           # Convolution kernels
│   │   └── conv2d.metal
│   └── activation/     # Activation functions
│       ├── relu.metal
│       ├── gelu.metal
│       └── softmax.metal
│
├── cuda/steel/         # CUDA ML kernels
│   ├── gemm.cu
│   ├── attention.cu
│   └── conv.cu
│
└── webgpu/steel/       # WebGPU ML shaders
    ├── gemm.wgsl
    └── attention.wgsl
```

## Example: Transformer Inference

```go
package main

import (
    "github.com/luxfi/accel"
    "math"
)

type TransformerLayer struct {
    QKVWeight *accel.Tensor[float32]
    QKVBias   *accel.Tensor[float32]
    OutWeight *accel.Tensor[float32]
    OutBias   *accel.Tensor[float32]
    FFN1Weight *accel.Tensor[float32]
    FFN1Bias   *accel.Tensor[float32]
    FFN2Weight *accel.Tensor[float32]
    FFN2Bias   *accel.Tensor[float32]
    LN1Gamma  *accel.Tensor[float32]
    LN1Beta   *accel.Tensor[float32]
    LN2Gamma  *accel.Tensor[float32]
    LN2Beta   *accel.Tensor[float32]
}

func transformerLayer(session *accel.Session, input *accel.Tensor[float32],
    layer *TransformerLayer, batchSize, seqLen, hiddenSize, numHeads int) (*accel.Tensor[float32], error) {

    ml := session.ML()
    headDim := hiddenSize / numHeads
    scale := float32(1.0 / math.Sqrt(float64(headDim)))

    // Pre-norm
    normed, _ := accel.NewTensor[float32](session, []int{batchSize, seqLen, hiddenSize})
    if err := ml.LayerNorm(input.Untyped(), layer.LN1Gamma.Untyped(),
        layer.LN1Beta.Untyped(), normed.Untyped(), 1e-5); err != nil {
        return nil, err
    }

    // QKV projection
    qkv, _ := accel.NewTensor[float32](session, []int{batchSize, seqLen, hiddenSize * 3})
    if err := ml.MatMul(normed.Untyped(), layer.QKVWeight.Untyped(), qkv.Untyped()); err != nil {
        return nil, err
    }
    if err := ml.Add(qkv.Untyped(), layer.QKVBias.Untyped(), qkv.Untyped()); err != nil {
        return nil, err
    }

    // Split Q, K, V and reshape for multi-head attention
    // [batch, seq, 3*hidden] -> 3x [batch, heads, seq, head_dim]
    q, k, v := splitQKV(qkv, batchSize, seqLen, numHeads, headDim)

    // Attention
    attnOut, _ := accel.NewTensor[float32](session, []int{batchSize, numHeads, seqLen, headDim})
    if err := ml.Attention(q.Untyped(), k.Untyped(), v.Untyped(), attnOut.Untyped(), scale); err != nil {
        return nil, err
    }

    // Project and residual
    projected, _ := accel.NewTensor[float32](session, []int{batchSize, seqLen, hiddenSize})
    reshaped := reshapeToSeq(attnOut, batchSize, seqLen, hiddenSize)
    if err := ml.MatMul(reshaped.Untyped(), layer.OutWeight.Untyped(), projected.Untyped()); err != nil {
        return nil, err
    }
    if err := ml.Add(input.Untyped(), projected.Untyped(), projected.Untyped()); err != nil {
        return nil, err
    }

    // FFN block
    normed2, _ := accel.NewTensor[float32](session, []int{batchSize, seqLen, hiddenSize})
    if err := ml.LayerNorm(projected.Untyped(), layer.LN2Gamma.Untyped(),
        layer.LN2Beta.Untyped(), normed2.Untyped(), 1e-5); err != nil {
        return nil, err
    }

    ffn1, _ := accel.NewTensor[float32](session, []int{batchSize, seqLen, hiddenSize * 4})
    if err := ml.MatMul(normed2.Untyped(), layer.FFN1Weight.Untyped(), ffn1.Untyped()); err != nil {
        return nil, err
    }
    if err := ml.GELU(ffn1.Untyped(), ffn1.Untyped()); err != nil {
        return nil, err
    }

    ffn2, _ := accel.NewTensor[float32](session, []int{batchSize, seqLen, hiddenSize})
    if err := ml.MatMul(ffn1.Untyped(), layer.FFN2Weight.Untyped(), ffn2.Untyped()); err != nil {
        return nil, err
    }

    // Final residual
    output, _ := accel.NewTensor[float32](session, []int{batchSize, seqLen, hiddenSize})
    if err := ml.Add(projected.Untyped(), ffn2.Untyped(), output.Untyped()); err != nil {
        return nil, err
    }

    return output, nil
}
```

## Data Type Support

| Operation | float32 | float16 | int32 | int64 |
|-----------|---------|---------|-------|-------|
| MatMul | Yes | Yes* | No | No |
| Attention | Yes | Yes* | No | No |
| Conv2D | Yes | Yes* | No | No |
| Activations | Yes | Yes* | No | No |
| Reductions | Yes | Yes* | Yes | Yes |

*FP16 requires `CapFP16` device capability.
