# Lux Accel

Lux Accel is a Go package providing GPU-accelerated operations for cryptography, zero-knowledge proofs, fully homomorphic encryption, and machine learning. It integrates with the Lux blockchain node for high-performance transaction verification and smart contract execution.

## Features

- **Multi-Backend Support**: Metal (Apple Silicon), CUDA (NVIDIA), WebGPU (cross-platform)
- **Cryptographic Operations**: BLS, ECDSA, Ed25519, SHA-256, Keccak, Poseidon hashing
- **Post-Quantum Crypto**: ML-KEM (Kyber) key encapsulation, ML-DSA (Dilithium) signatures
- **Zero-Knowledge**: NTT/INTT transforms, MSM, polynomial operations, KZG commitments
- **FHE**: BFV (exact) and CKKS (approximate) homomorphic encryption schemes
- **ML Operations**: MatMul, attention, convolutions, activations, layer normalization
- **Tensor API**: Type-safe generic tensors with GPU memory management

## Quick Start

### Installation

```go
go get github.com/luxfi/accel@latest
```

### Basic Usage

```go
package main

import (
    "fmt"
    "log"

    "github.com/luxfi/accel"
)

func main() {
    // Initialize the library
    if err := accel.Init(); err != nil {
        log.Fatal(err)
    }
    defer accel.Shutdown()

    // Check available backends
    fmt.Println("Available backends:", accel.Backends())
    fmt.Println("Available devices:", accel.DeviceCount())

    // Create a session (auto-selects best backend)
    session, err := accel.NewSession()
    if err != nil {
        log.Fatal(err)
    }
    defer session.Close()

    // Get device info
    info := session.DeviceInfo()
    fmt.Printf("Using: %s (%s)\n", info.Name, info.Backend)
    fmt.Printf("Memory: %.2f GB\n", info.MemoryGB())

    // Create tensors and perform operations
    a, _ := accel.NewTensorWithData[float32](session, []int{1024, 1024}, makeMatrix(1024*1024))
    b, _ := accel.NewTensorWithData[float32](session, []int{1024, 1024}, makeMatrix(1024*1024))
    c, _ := accel.NewTensor[float32](session, []int{1024, 1024})
    defer a.Close()
    defer b.Close()
    defer c.Close()

    // GPU matrix multiplication
    if err := session.ML().MatMul(a.Untyped(), b.Untyped(), c.Untyped()); err != nil {
        log.Fatal(err)
    }

    // Sync and get result
    session.Sync()
    result, _ := c.ToSlice()
    fmt.Println("Result[0]:", result[0])
}

func makeMatrix(n int) []float32 {
    m := make([]float32, n)
    for i := range m {
        m[i] = float32(i % 100) / 100.0
    }
    return m
}
```

## Architecture

```text
accel/
├── accel.go           # Main API: Init, Shutdown, NewSession
├── session.go         # Session management, operation dispatching
├── tensor.go          # Generic tensor with GPU memory
├── backend.go         # Backend types: Metal, CUDA, WebGPU
├── device.go          # Device info and capabilities
├── dtype.go           # Data types: float32, int64, uint8, etc.
│
├── ops_crypto.go      # CryptoOps interface
├── ops_zk.go          # ZKOps interface
├── ops_fhe.go         # FHEOps interface
├── ops_ml.go          # MLOps interface
├── ops_lattice.go     # LatticeOps interface (post-quantum)
├── ops_dex.go         # DEXOps interface (orderbook)
│
└── internal/
    └── capi/          # C API bindings to lux-accel library
```

### C++ Backend Libraries

The Go package wraps C++ libraries located at `/Users/z/work/luxcpp/`:

| Library | Path | Purpose |
|---------|------|---------|
| lux-accel | `/luxcpp/lux-accel/` | Unified C API |
| lux-gpu | `/luxcpp/lux-gpu/` | Device/kernel management |
| lux-metal | `/luxcpp/lux-metal/` | Metal backend plugin |
| lux-cuda | `/luxcpp/lux-cuda/` | CUDA backend plugin |
| lux-webgpu | `/luxcpp/lux-webgpu/` | WebGPU backend plugin |
| crypto | `/luxcpp/crypto/` | Cryptographic operations |
| lattice | `/luxcpp/lattice/` | Lattice cryptography |
| fhe | `/luxcpp/fhe/` | FHE (OpenFHE-based) |

## Operation Interfaces

The Session provides access to specialized operation interfaces:

```go
session.ML()       // MLOps - machine learning operations
session.Crypto()   // CryptoOps - cryptographic operations
session.ZK()       // ZKOps - zero-knowledge operations
session.FHE()      // FHEOps - homomorphic encryption
session.Lattice()  // LatticeOps - post-quantum crypto
session.DEX()      // DEXOps - exchange operations
```
