# ZK Operations

The `ZKOps` interface provides GPU-accelerated operations for zero-knowledge proof systems.

## Overview

```go
zk := session.ZK()
```

Operations include:
- **NTT/INTT**: Number Theoretic Transform
- **MSM**: Multi-Scalar Multiplication
- **Polynomial**: Multiplication, evaluation, commitment
- **FFT**: Fast Fourier Transform (complex)
- **Field Operations**: Add, multiply, inverse

## Number Theoretic Transform

### NTT

Performs Number Theoretic Transform for polynomial multiplication in ZK circuits.

```go
// NTT(input, output, roots *UntypedTensor, modulus uint64) error
// input: [N] uint64 coefficients
// output: [N] uint64 NTT values
// roots: [N] uint64 roots of unity
// modulus: prime modulus

// Goldilocks prime (2^64 - 2^32 + 1)
const goldilocks = uint64(0xFFFFFFFF00000001)

n := 1 << 20  // 2^20 = 1M coefficients
input, _ := accel.NewTensorWithData[uint64](session, []int{n}, coefficients)
output, _ := accel.NewTensor[uint64](session, []int{n})
roots, _ := accel.NewTensorWithData[uint64](session, []int{n}, rootsOfUnity)

if err := session.ZK().NTT(
    input.Untyped(),
    output.Untyped(),
    roots.Untyped(),
    goldilocks,
); err != nil {
    log.Fatal(err)
}

nttValues, _ := output.ToSlice()
```

### INTT

Performs inverse NTT to convert back to coefficient form.

```go
// INTT(input, output, invRoots *UntypedTensor, modulus uint64) error
// input: [N] uint64 NTT values
// output: [N] uint64 coefficients
// invRoots: [N] uint64 inverse roots of unity
// modulus: prime modulus

if err := session.ZK().INTT(
    nttValues.Untyped(),
    coefficients.Untyped(),
    invRoots.Untyped(),
    goldilocks,
); err != nil {
    log.Fatal(err)
}
```

## Multi-Scalar Multiplication

### MSM

Performs multi-scalar multiplication on elliptic curves for KZG commitments and Groth16 proofs.

```go
// MSM(scalars, bases, result *UntypedTensor) error
// scalars: [N, scalar_size] bytes
// bases: [N, point_size] bytes (affine points)
// result: [point_size] bytes

// BLS12-381 curve: 32-byte scalars, 96-byte G1 points
n := 1 << 16  // 64K points
scalars, _ := accel.NewTensorWithData[uint8](session, []int{n, 32}, scalarData)
bases, _ := accel.NewTensorWithData[uint8](session, []int{n, 96}, pointData)
result, _ := accel.NewTensor[uint8](session, []int{96})

if err := session.ZK().MSM(
    scalars.Untyped(),
    bases.Untyped(),
    result.Untyped(),
); err != nil {
    log.Fatal(err)
}

commitment, _ := result.ToSlice()
// commitment contains the resulting EC point
```

### MSMBatch

Performs multiple MSMs in parallel.

```go
// MSMBatch(scalars, bases, results *UntypedTensor) error
// scalars: [M, N, scalar_size] bytes
// bases: [M, N, point_size] bytes
// results: [M, point_size] bytes

// Compute 100 MSMs, each with 1024 points
batchSize := 100
pointsPerMSM := 1024

scalars, _ := accel.NewTensorWithData[uint8](session,
    []int{batchSize, pointsPerMSM, 32}, allScalars)
bases, _ := accel.NewTensorWithData[uint8](session,
    []int{batchSize, pointsPerMSM, 96}, allBases)
results, _ := accel.NewTensor[uint8](session, []int{batchSize, 96})

if err := session.ZK().MSMBatch(
    scalars.Untyped(),
    bases.Untyped(),
    results.Untyped(),
); err != nil {
    log.Fatal(err)
}
```

## Polynomial Operations

### PolyMul

Multiplies polynomials in coefficient form.

```go
// PolyMul(a, b, c *UntypedTensor, modulus uint64) error
// a: [N] uint64 coefficients
// b: [N] uint64 coefficients
// c: [2N-1] uint64 result coefficients
// modulus: prime modulus

n := 1024
a, _ := accel.NewTensorWithData[uint64](session, []int{n}, coeffsA)
b, _ := accel.NewTensorWithData[uint64](session, []int{n}, coeffsB)
c, _ := accel.NewTensor[uint64](session, []int{2*n - 1})

if err := session.ZK().PolyMul(a.Untyped(), b.Untyped(), c.Untyped(), goldilocks); err != nil {
    log.Fatal(err)
}
```

### PolyEval

Evaluates polynomial at given points.

```go
// PolyEval(coeffs, points, results *UntypedTensor, modulus uint64) error
// coeffs: [degree+1] uint64
// points: [N] uint64
// results: [N] uint64
// modulus: prime modulus

degree := 1024
numPoints := 10000

coeffs, _ := accel.NewTensorWithData[uint64](session, []int{degree + 1}, polyCoeffs)
points, _ := accel.NewTensorWithData[uint64](session, []int{numPoints}, evalPoints)
results, _ := accel.NewTensor[uint64](session, []int{numPoints})

if err := session.ZK().PolyEval(
    coeffs.Untyped(),
    points.Untyped(),
    results.Untyped(),
    goldilocks,
); err != nil {
    log.Fatal(err)
}

evaluations, _ := results.ToSlice()
```

### CommitPoly

Computes polynomial commitment (KZG).

```go
// CommitPoly(coeffs, srs, commitment *UntypedTensor) error
// coeffs: [degree+1, field_size] bytes
// srs: structured reference string
// commitment: [point_size] bytes

degree := 4096
coeffs, _ := accel.NewTensorWithData[uint8](session, []int{degree + 1, 32}, coeffData)
srs, _ := accel.NewTensorWithData[uint8](session, []int{degree + 1, 96}, srsData)
commitment, _ := accel.NewTensor[uint8](session, []int{96})

if err := session.ZK().CommitPoly(
    coeffs.Untyped(),
    srs.Untyped(),
    commitment.Untyped(),
); err != nil {
    log.Fatal(err)
}
```

## Fast Fourier Transform

### FFT

Performs Fast Fourier Transform (complex-valued).

```go
// FFT(input, output *UntypedTensor) error
// input: [N, 2] float32 (real, imag)
// output: [N, 2] float32

n := 1 << 16
input, _ := accel.NewTensorWithData[float32](session, []int{n, 2}, complexData)
output, _ := accel.NewTensor[float32](session, []int{n, 2})

if err := session.ZK().FFT(input.Untyped(), output.Untyped()); err != nil {
    log.Fatal(err)
}
```

### IFFT

Performs inverse FFT.

```go
// IFFT(input, output *UntypedTensor) error

if err := session.ZK().IFFT(input.Untyped(), output.Untyped()); err != nil {
    log.Fatal(err)
}
```

## Field Operations

### FieldAdd

Adds field elements modulo a prime.

```go
// FieldAdd(a, b, c *UntypedTensor, modulus uint64) error
// a: [N] uint64
// b: [N] uint64
// c: [N] uint64 (result)
// modulus: prime modulus

n := 1000000
a, _ := accel.NewTensorWithData[uint64](session, []int{n}, dataA)
b, _ := accel.NewTensorWithData[uint64](session, []int{n}, dataB)
c, _ := accel.NewTensor[uint64](session, []int{n})

if err := session.ZK().FieldAdd(a.Untyped(), b.Untyped(), c.Untyped(), goldilocks); err != nil {
    log.Fatal(err)
}
```

### FieldMul

Multiplies field elements.

```go
// FieldMul(a, b, c *UntypedTensor, modulus uint64) error

if err := session.ZK().FieldMul(a.Untyped(), b.Untyped(), c.Untyped(), goldilocks); err != nil {
    log.Fatal(err)
}
```

### FieldInv

Computes modular inverse.

```go
// FieldInv(a, b *UntypedTensor, modulus uint64) error
// b[i] = a[i]^(-1) mod modulus

if err := session.ZK().FieldInv(a.Untyped(), b.Untyped(), goldilocks); err != nil {
    log.Fatal(err)
}
```

## Example: STARK Proof Generation

```go
package main

import (
    "github.com/luxfi/accel"
)

func generateSTARKProof(session *accel.Session, trace []uint64) (*Proof, error) {
    zk := session.ZK()

    // 1. Extend trace with NTT
    traceLen := len(trace)
    extendedLen := traceLen * 8  // blow-up factor of 8

    traceT, _ := accel.NewTensorWithData[uint64](session, []int{traceLen}, trace)
    extended, _ := accel.NewTensor[uint64](session, []int{extendedLen})
    roots, _ := accel.NewTensorWithData[uint64](session, []int{extendedLen}, computeRoots(extendedLen))

    // NTT for polynomial evaluation
    if err := zk.NTT(traceT.Untyped(), extended.Untyped(), roots.Untyped(), goldilocks); err != nil {
        return nil, err
    }

    // 2. Compute constraint polynomial
    // ... polynomial composition

    // 3. Commit to polynomials
    coeffs := computeCoeffs(extended)
    commitment, _ := accel.NewTensor[uint8](session, []int{96})
    srs := loadSRS()

    if err := zk.CommitPoly(coeffs.Untyped(), srs.Untyped(), commitment.Untyped()); err != nil {
        return nil, err
    }

    // 4. Generate FRI proof
    // ... FRI folding with NTT

    session.Sync()

    return &Proof{
        Commitment: commitment,
        // ... other proof elements
    }, nil
}
```

## Supported Fields and Curves

### Prime Fields

| Field | Modulus | Bits |
|-------|---------|------|
| Goldilocks | 2^64 - 2^32 + 1 | 64 |
| BN254 | 21888...32257 | 254 |
| BLS12-381 | p (381-bit) | 381 |

### Elliptic Curves

| Curve | Use Case | Point Size |
|-------|----------|------------|
| BN254 | Groth16, PLONK | 64 bytes (G1) |
| BLS12-381 | KZG, aggregation | 96 bytes (G1) |
| Secp256k1 | ECDSA | 64 bytes |
