# Crypto Operations

The `CryptoOps` interface provides GPU-accelerated cryptographic operations for blockchain applications.

## Overview

```go
crypto := session.Crypto()
```

Operations include:
- **Hashing**: SHA-256, Keccak-256, Poseidon
- **Signatures**: ECDSA, Ed25519, BLS verification
- **BLS Aggregation**: Aggregate multiple signatures
- **Merkle Trees**: Root computation and proof generation

## Hashing Operations

### SHA256

Computes SHA-256 hashes for a batch of inputs.

```go
// SHA256(input, output *UntypedTensor) error
// input: [N, input_len] bytes
// output: [N, 32] bytes

// Hash 1000 messages of 64 bytes each
input, _ := accel.NewTensorWithData[uint8](session, []int{1000, 64}, messages)
output, _ := accel.NewTensor[uint8](session, []int{1000, 32})
defer input.Close()
defer output.Close()

if err := session.Crypto().SHA256(input.Untyped(), output.Untyped()); err != nil {
    log.Fatal(err)
}

hashes, _ := output.ToSlice()
// hashes[i*32:(i+1)*32] contains hash of messages[i*64:(i+1)*64]
```

### Keccak256

Computes Keccak-256 (Ethereum hash) for a batch of inputs.

```go
// Keccak256(input, output *UntypedTensor) error
// input: [N, input_len] bytes
// output: [N, 32] bytes

if err := session.Crypto().Keccak256(input.Untyped(), output.Untyped()); err != nil {
    log.Fatal(err)
}
```

### Poseidon

Computes Poseidon hash (ZK-friendly hash function).

```go
// Poseidon(input, output *UntypedTensor) error
// input: [N, field_elements] uint64
// output: [N, 1] uint64

// Hash field elements (e.g., for ZK circuits)
input, _ := accel.NewTensorWithData[uint64](session, []int{1000, 8}, fieldElements)
output, _ := accel.NewTensor[uint64](session, []int{1000, 1})

if err := session.Crypto().Poseidon(input.Untyped(), output.Untyped()); err != nil {
    log.Fatal(err)
}
```

## Signature Verification

### ECDSAVerifyBatch

Verifies multiple ECDSA signatures in parallel (secp256k1).

```go
// ECDSAVerifyBatch(messages, signatures, pubkeys, results *UntypedTensor) error
// messages: [N, 32] bytes (message hashes)
// signatures: [N, 64] bytes (r || s)
// pubkeys: [N, 33] bytes (compressed) or [N, 65] (uncompressed)
// results: [N] uint8 (1 = valid, 0 = invalid)

messages, _ := accel.NewTensorWithData[uint8](session, []int{batchSize, 32}, msgHashes)
signatures, _ := accel.NewTensorWithData[uint8](session, []int{batchSize, 64}, sigs)
pubkeys, _ := accel.NewTensorWithData[uint8](session, []int{batchSize, 33}, pks)
results, _ := accel.NewTensor[uint8](session, []int{batchSize})

if err := session.Crypto().ECDSAVerifyBatch(
    messages.Untyped(),
    signatures.Untyped(),
    pubkeys.Untyped(),
    results.Untyped(),
); err != nil {
    log.Fatal(err)
}

valid, _ := results.ToSlice()
for i, v := range valid {
    if v == 1 {
        fmt.Printf("Signature %d is valid\n", i)
    }
}
```

### Ed25519VerifyBatch

Verifies multiple Ed25519 signatures.

```go
// Ed25519VerifyBatch(messages, signatures, pubkeys, results *UntypedTensor) error
// messages: [N, msg_len] bytes
// signatures: [N, 64] bytes
// pubkeys: [N, 32] bytes
// results: [N] uint8 (1 = valid, 0 = invalid)

if err := session.Crypto().Ed25519VerifyBatch(
    messages.Untyped(),
    signatures.Untyped(),
    pubkeys.Untyped(),
    results.Untyped(),
); err != nil {
    log.Fatal(err)
}
```

### BLSVerifyBatch

Verifies multiple BLS signatures on the BLS12-381 curve.

```go
// BLSVerifyBatch(messages, signatures, pubkeys, results *UntypedTensor) error
// messages: [N, msg_len] bytes
// signatures: [N, 96] bytes (G2 points)
// pubkeys: [N, 48] bytes (G1 points)
// results: [N] uint8 (1 = valid, 0 = invalid)

messages, _ := accel.NewTensorWithData[uint8](session, []int{batchSize, 32}, msgs)
signatures, _ := accel.NewTensorWithData[uint8](session, []int{batchSize, 96}, blsSigs)
pubkeys, _ := accel.NewTensorWithData[uint8](session, []int{batchSize, 48}, blsPks)
results, _ := accel.NewTensor[uint8](session, []int{batchSize})

if err := session.Crypto().BLSVerifyBatch(
    messages.Untyped(),
    signatures.Untyped(),
    pubkeys.Untyped(),
    results.Untyped(),
); err != nil {
    log.Fatal(err)
}
```

## BLS Aggregation

### BLSAggregate

Aggregates multiple BLS signatures into one.

```go
// BLSAggregate(signatures, aggregated *UntypedTensor) error
// signatures: [N, 96] bytes
// aggregated: [96] bytes

signatures, _ := accel.NewTensorWithData[uint8](session, []int{100, 96}, blsSigs)
aggregated, _ := accel.NewTensor[uint8](session, []int{96})

if err := session.Crypto().BLSAggregate(
    signatures.Untyped(),
    aggregated.Untyped(),
); err != nil {
    log.Fatal(err)
}

aggSig, _ := aggregated.ToSlice()
// aggSig contains the aggregated signature
```

## Merkle Trees

### MerkleRoot

Computes Merkle root from leaves.

```go
// MerkleRoot(leaves, root *UntypedTensor) error
// leaves: [N, 32] bytes (N must be power of 2)
// root: [32] bytes

// Create leaves (power of 2)
numLeaves := 1024  // Must be power of 2
leaves, _ := accel.NewTensorWithData[uint8](session, []int{numLeaves, 32}, leafData)
root, _ := accel.NewTensor[uint8](session, []int{32})

if err := session.Crypto().MerkleRoot(leaves.Untyped(), root.Untyped()); err != nil {
    log.Fatal(err)
}

rootHash, _ := root.ToSlice()
fmt.Printf("Merkle root: %x\n", rootHash)
```

### MerkleBatch

Computes multiple Merkle roots in parallel.

```go
// MerkleBatch(leavesSet, roots *UntypedTensor) error
// leavesSet: [M, N, 32] bytes
// roots: [M, 32] bytes

// Compute 100 Merkle roots, each with 256 leaves
leavesSet, _ := accel.NewTensorWithData[uint8](session, []int{100, 256, 32}, allLeaves)
roots, _ := accel.NewTensor[uint8](session, []int{100, 32})

if err := session.Crypto().MerkleBatch(leavesSet.Untyped(), roots.Untyped()); err != nil {
    log.Fatal(err)
}
```

### MerkleProof

Generates Merkle proof for a leaf.

```go
// MerkleProof(leaves *UntypedTensor, leafIndex int, proof *UntypedTensor) error
// leaves: [N, 32] bytes
// leafIndex: index of the leaf
// proof: [log2(N), 32] bytes

numLeaves := 1024
proofLen := 10  // log2(1024) = 10

leaves, _ := accel.NewTensorWithData[uint8](session, []int{numLeaves, 32}, leafData)
proof, _ := accel.NewTensor[uint8](session, []int{proofLen, 32})

leafIndex := 42
if err := session.Crypto().MerkleProof(leaves.Untyped(), leafIndex, proof.Untyped()); err != nil {
    log.Fatal(err)
}

proofHashes, _ := proof.ToSlice()
// proofHashes contains the Merkle proof
```

## Example: Block Verification

Complete example verifying a block with multiple transaction types:

```go
package main

import (
    "log"
    "github.com/luxfi/accel"
)

func verifyBlock(session *accel.Session, block *Block) error {
    crypto := session.Crypto()

    // 1. Hash all transactions
    txData := flattenTxData(block.Transactions)
    txHashes, _ := accel.NewTensor[uint8](session, []int{len(block.Transactions), 32})
    txInput, _ := accel.NewTensorWithData[uint8](session,
        []int{len(block.Transactions), maxTxSize}, txData)

    if err := crypto.Keccak256(txInput.Untyped(), txHashes.Untyped()); err != nil {
        return err
    }

    // 2. Verify ECDSA signatures
    ecdsaSigs := filterECDSA(block.Transactions)
    if len(ecdsaSigs) > 0 {
        // ... setup tensors
        if err := crypto.ECDSAVerifyBatch(msgs, sigs, pks, results); err != nil {
            return err
        }
    }

    // 3. Verify BLS signatures (validator signatures)
    blsSigs := filterBLS(block.ValidatorSigs)
    if len(blsSigs) > 0 {
        // ... setup tensors
        if err := crypto.BLSVerifyBatch(msgs, sigs, pks, results); err != nil {
            return err
        }
    }

    // 4. Compute Merkle root and verify
    root, _ := accel.NewTensor[uint8](session, []int{32})
    if err := crypto.MerkleRoot(txHashes.Untyped(), root.Untyped()); err != nil {
        return err
    }

    session.Sync()
    // Verify root matches block header
    // ...

    return nil
}
```
